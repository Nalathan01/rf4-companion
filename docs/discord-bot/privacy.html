Was der Bot liest

Der Bot liest nur Nachrichten in den Kanälen, die ein Server-Admin für ihn freigegeben hat und die nach einem Gewässer benannt sind oder "Spot", "Aufgabe" oder "Herausforderung" im Namen tragen, auch über den Namen ihrer Kategorie. Gelesen werden der Nachrichtentext, angehängte Bilder, der Zeitpunkt der Nachricht und die Kennungen von Server, Kanal und Nachricht. Alle 15 Minuten werden die Nachrichten dieser Kanäle abgefragt, auch ältere.

Was gespeichert und veröffentlicht wird

Aus einer Nachricht werden nur Angaben zum Spot übernommen:

  • Gewässer, Koordinaten, Clip, Tiefe, Wassertemperatur
  • Fischarten und Gewicht des größten Fischs, Köder und Dips, Wurfrichtung
  • Datum der Nachricht und ein Link zur Nachricht auf Discord
  • Die angehängten Screenshots, verkleinert und ohne den linken Bildrand, in dem im Spiel der Chat und der eigene Spielername stehen
  • Kennung und Name des Servers, dazu ein Einladungslink, wenn der Server sein Widget freigegeben oder uns einen Link gegeben hat. Wer den Servernamen nicht zeigen möchte, sagt Nalathan Bescheid.

Diese Angaben stehen in einer öffentlichen Datei auf GitHub und werden in der App RF4 Companion angezeigt.

Was nicht gespeichert wird

  • Keine Benutzernamen, keine Benutzerkennungen, keine Profilbilder
  • Kein Nachrichtentext
  • Keine Nachrichten aus Kanälen, die nicht freigegeben sind, und keine Direktnachrichten

Wo die Verarbeitung läuft

Das Auslesen läuft automatisch auf GitHub Actions. Die App RF4 Companion selbst verbindet sich nie mit Discord.

Speicherdauer und Löschen

Spots und Bilder bleiben als Archiv erhalten, bis der Spot gelöscht wird.

Ein Admin kann den Bot jederzeit vom Server entfernen oder ihm die Kanäle wieder entziehen, dann liest er dort nichts mehr. Wer möchte, dass ein bestimmter Spot entfernt wird, meldet sich bei Nalathan auf Discord oder über GitHub.

Privacy policy

What the bot reads

The bot only reads messages in channels that a server admin has allowed for it and that are named after a waterbody or have "spot", "Aufgabe" or "Herausforderung" (task, challenge) in their name, also through the name of their category. It reads the message text, attached images, the message time and the server, channel and message IDs. Every 15 minutes it checks the messages of these channels, older ones included.

What is stored and published

Only spot details are taken from a message:

  • Waterbody, coordinates, clip, depth, water temperature
  • Fish and the weight of the biggest fish, baits and dips, cast direction
  • Date of the message and a link to the message on Discord
  • The attached screenshots, resized and without the left edge where the game shows the chat and your own player name
  • Server ID and name, plus an invite link if the server has its widget enabled or gave us a link. If you do not want your server name shown, tell Nalathan.

These details are kept in a public file on GitHub and shown in the RF4 Companion app.

What is not stored

  • No user names, no user IDs, no avatars
  • No message text
  • No messages from channels that are not allowed, and no direct messages

Where it runs

Reading runs automatically on GitHub Actions. The RF4 Companion app itself never connects to Discord.

Retention and removal

Spots and images are kept as an archive until the spot is removed.

An admin can remove the bot from the server or take away its channel access at any time, then it stops reading there. If you want a specific spot removed, contact Nalathan on Discord or via GitHub.
